## Project Description
Practice exercises for JavaScript fundamentals (variables, data types, functions,
control flow, arrays, objects, JSON), an interactive calculator, and a student
grade tracker.

## Technologies Used
- HTML5
- JavaScript (ES6)
- Git and GitHub

## Features
- Variable, data type and operator exercises
- Functions: declarations, expressions, arrow functions, default parameters
- Control flow: if/else, switch, for and while loops, FizzBuzz
- Interactive calculator supporting + - * / % ** with division-by-zero handling
- Array methods (map, filter, find, reduce, sort, some, every) and JSON parsing
- Student grade tracker with averages, top student and report cards
- Five daily challenges
